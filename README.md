## 🚀 Cara Menjalankan Website

### Opsi 1: Klik Ganda (Paling Cepat)
Cukup klik ganda file **`buka-website.bat`** di dalam folder `najwa-portfolio`. Website akan langsung terbuka di browser utama Anda (Chrome, Edge, dll.).

### Opsi 2: Buka File Langsung
Klik kanan pada file `index.html` -> Pilih **Open with** -> Pilih browser kesukaan Anda (Google Chrome / Microsoft Edge).

### Opsi 3: Deploy Online Gratis (Opsional)
Website ini bersifat static (HTML/CSS/JS murni tanpa backend khusus), sehingga dapat langsung di-hosting secara gratis di:
- **GitHub Pages**
- **Vercel** (`vercel deploy`)
- **Netlify** (cukup drag and drop folder ke dashboard Netlify)
